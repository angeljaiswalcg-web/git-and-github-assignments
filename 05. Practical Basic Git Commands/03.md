Assignment 3: Practical – Clone + Basic Workflow
Objective: Perform the complete basic Git workflow.

Tasks:

Fork any simple public repository or use your own repository.
Clone it to your local system.
Create a new file named day5.txt and write:
Your full name
One Git command you learned today

git status
git add .
git status
git commit -m "Added day5 practice file"
git push origin main
Verify that the file appears on GitHub.
