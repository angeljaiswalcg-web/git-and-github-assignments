Bonus – Peer Review Simulation (Optional)
Pair with a classmate (or use two clones):

Person A creates a feature branch (example: feature/footer) and opens a PR.
Person B leaves a meaningful review comment requesting a small improvement.
Person A reworks, pushes, and asks for re-review.
Person B approves; Person A merges and completes cleanup.
Both update their local main and confirm the file is present.
Submit (optional): PR link showing the review conversation + photo short note on what you learned.
