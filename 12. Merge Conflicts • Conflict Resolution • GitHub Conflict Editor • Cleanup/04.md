Bonus – Resolve a Conflict Locally (Optional)
Create two branches that change the same line of a file.
Merge the first branch into main locally.
Merge the second branch → conflict appears in the terminal.
Open the file, resolve the markers manually, then:
git add .
git commit -m "Resolve merge conflict locally"
Push the result.
Submit (optional): Screenshot of the conflicted file and the resolution commit.
